# Third-Party Notices

TactileMac is an original Swift/SwiftUI implementation. No third-party source
code, binaries, or audio recordings are bundled in the application.

Audio decoding uses Apple's AVFoundation and Core Audio system frameworks. No
third-party decoder library is bundled or redistributed.

Sound packs imported by the user remain in their Application Support folder and
are not redistributed by TactileMac. Imported content is validated and decoded,
never executed.

This build is ad-hoc signed and is not Developer ID signed or notarized in the
current environment.
